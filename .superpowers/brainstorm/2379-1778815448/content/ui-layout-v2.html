主页面职责

  • 文件上传 / 文本粘贴
  • 参数配置（折叠）
  • 触发拆分 → 跳转结果页
  • 服务状态灯
  • 极简，快速加载

结果页面职责

  • 摘要统计栏
  • 分页表格（默认50条/页）
  • 内容搜索 + 类型过滤
  • 行展开查看完整内容
  • 导出 Excel
  • 返回主页面

大数据量策略

  • 服务端不做分页，一次返回全量 JSON
  • UI 端内存分页，避免二次请求
  • 虚拟滚动备选（千条以上）
  • 搜索/过滤在内存中完成
