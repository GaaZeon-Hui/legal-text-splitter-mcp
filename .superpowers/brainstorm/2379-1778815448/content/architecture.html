Section 1 — Overall Architecture

Dual process: NiceGUI UI + FastAPI Service

Data Flow: 原文进，片段出
📁 文件上传
.txt .docx .xlsx
→
🖥 NiceGUI
:8080
→
⚙ FastAPI
:8001
→
📊 结果表格

1. UI 收到文件 → 解析提取纯文本

2. UI 调用 POST /api/split {text: "…", params: {…}}

3. Service 执行 保护块 → 清洗 → 分析 → 拆分 → 回卷

4. Service 返回 {fragments: […], meta: {…}}

5. UI 渲染 表格 + 统计摘要

NiceGUI 前端 (port 8080)

  • 文件上传 / 拖拽区域
  • 算法参数面板（预留）
  • 拆分结果表格（主视图）
  • 统计摘要行
  • 导出按钮（Excel 下载）
  • 服务连接状态指示灯

FastAPI 服务 (port 8001)

  • GET /health — 健康检查
  • POST /api/split — 分析 + 拆分
  • 复用现有 _protection_config
  • 复用现有 analyze_scored
  • 复用现有 post-类型拆分 拆分引擎
  • 返回 JSON 片段列表
