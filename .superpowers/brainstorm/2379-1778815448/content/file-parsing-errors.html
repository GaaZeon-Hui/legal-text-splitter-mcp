Section 4 — File Parsing & Error Handling

上传 → 解析 → 校验 → 发送

支持的文件格式 & 解析策略

格式 解析方式 说明
.txt 直接读取 UTF-8 / GBK 自动编码检测（chardet 或逐 trial）
.docx python-docx 提取段落文本 按段落用 \n 拼接，忽略格式
.xlsx openpyxl 读取内容列 指定列/全部列拼接；可后续支持映射
粘贴文本 直接使用 textarea 输入，优先于文件上传

解析流程

1. 用户上传文件 → UI 检查扩展名（白名单：.txt .docx .xlsx）

2. 调对应解析器提取纯文本

3. 文本校验：非空 + 长度 < 10MB（防超大文件）

4. 填充到隐藏的 text 变量中 → POST /api/split

5. 等待响应 → 成功则跳转结果页；失败则主页面展示错误

错误场景 & 处理

场景UI 表现
格式不支持上传区变红 + toast 提示
文件过大 (>10MB)上传区变红 + 提示大小限制
解析失败toast 提示具体原因
文本为空拆分按钮保持禁用
服务不可达状态灯变红 + 拆分按钮禁用 + toast
服务返回错误主页面 toast 展示错误信息，不跳转
请求超时 (30s)loading 状态结束 + toast 超时提示
拆分结果为 0 片段依然跳转结果页，显示"未能拆分"

UI 状态机

IDLE — 初始，等待输入
  → 文本就绪 → READY（按钮激活）
  → 服务断连 → DISCONNECTED（按钮禁用）

READY — 有文本，可拆分
  → 点击拆分 → LOADING
  → 文本被清空 → IDLE

LOADING — 按钮显示 spinner
  → 成功 → 跳转结果页
  → 失败/超时 → READY + toast

DISCONNECTED — 服务不可达
  → 定时重试 /health
  → 恢复 → IDLE
