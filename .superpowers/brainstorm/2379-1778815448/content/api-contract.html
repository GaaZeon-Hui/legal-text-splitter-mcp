Section 2 — API Contract

FastAPI service endpoints

GET /health

Response 200:

{
  "status": "ok",
  "version": "1.0.0",
  "algorithms": ["scored", "legacy"]
}

POST /api/split

Request body:

{
  "text": "第一条 …\n第二条 …\n第一章 …",
  "params": {                              // 可选，算法参数（未来扩展）
    "algorithm": "scored",                 // "scored" | "legacy"
    "split_types": null,                   // null=自动检测, 或 ["条","章","节"]
    "min_fragment_chars": 10               // 最短片段阈值
  }
}

Response 200:

{
  "law_id": null,
  "fragments": [
    {
      "seq": 1,
      "content": "第一条 为了规范市场秩序…",
      "split_type": "条",
      "index_level": 3,
      "ordinal": 1
    },
    {
      "seq": 2,
      "content": "第二条 市场准入…",
      "split_type": "条",
      "index_level": 3,
      "ordinal": 2
    }
  ],
  "meta": {
    "char_count": 1234,
    "fragment_count": 15,
    "spine_types": ["条"],
    "all_tags": ["条", "章", "括号"],
    "level_chain": "章→条",
    "processing_ms": 42,
    "algorithm": "scored"
  }
}

Response 422 (空/无效文本):

{
  "detail": "文本为空或无法解析"
}

fragment 字段说明

seq片段序号（1-based）
content片段完整文本
split_type拆分类型：条/章/节/编/括号/数字点/… 或 null
index_level层级深度（0=最外层，递增），由差分权重法推断
ordinal该片段在原文档中的序数值（如第3条 → 3）
