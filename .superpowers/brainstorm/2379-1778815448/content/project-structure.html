app/main.py

NiceGUI 启动入口。注册页面路由，全局 header/状态。唯一的 ui.run() 调用。

启动时自动检测服务连接状态（调 /health），断连则显示警告。

service/main.py

FastAPI 服务入口。注册 /health 和 /api/split 端点。导入现有的 _protection_config、analyze_scored、post-类型拆分 模块。

CORS 开启（允许 UI 跨域），单 worker 运行在 :8001。

关键原则

  • 不修改任何现有 .py 文件（纯新增）
  • UI 端不 import 任何分析模块
  • 服务端包一层薄薄的 FastAPI → 调现有函数
  • 两端通过 JSON 合约通信
